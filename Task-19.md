# Task 19

Краткое описание изменений за сегодня:

- Упростили консольный вывод при вызове MCP-инструментов: теперь показывается только выбранный инструмент без аргументов, результата и деталей ошибки.
- Усилили системный промпт агента: при многошаговых задачах он должен последовательно вызывать MCP-инструменты и передавать результат предыдущего вызова в следующий.
- Добавили константу `MAX_TOOL_CALL_ROUNDS = 8` для ограничения количества последовательных раундов вызова инструментов.
- Добавили проверку лимита tool-вызовов, чтобы агент не мог бесконечно выполнять цепочку инструментов.
- Добавили нормализацию естественных русскоязычных периодов вроде `сегодня`, `вчера`, `прошлая неделя`, `последняя неделя`, `за месяц` и `последние N часов/дней/месяцев` в ISO-8601 интервалы `from`/`to`.
- Агент теперь добавляет нормализованный временной контекст к пользовательскому запросу и использует его для периодических отчетов и сохранения `reportFrom`/`reportTo`.
- Разнесли разросшийся код по логическим пакетам:
  - `mcp_client.agent` — агент и нормализация времени;
  - `mcp_client.cli` — CLI-парсер, русский formatter и консольный чат;
  - `mcp_client.integrations` — OpenAI Responses API и MCP tools;
  - `mcp_client.config`, `mcp_client.errors`, `mcp_client.app` — общая конфигурация, ошибки и сборка приложения.
- Оставили `main.py` корневой точкой входа, а дефолтный `local.properties` по-прежнему резолвится из корня проекта.
- Перенесли тесты нормализации в `tests/test_time_normalization.py`.
- Проверили проект командами `.venv/bin/python -m compileall -q main.py mcp_client tests`, `.venv/bin/python -m unittest discover -s tests` и `.venv/bin/python main.py --help`.
